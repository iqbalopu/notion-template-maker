## Usage

Run the automated generator to create 10 random templates daily:

```bash
npm run auto-generate
```

Or generate specific templates manually:

```bash
node dist/cli/index.js auto-generate --count 5
```

## Template Structure

All templates follow a consistent structure:
- Clear headings and sections
- Actionable checklists and to-do items
- Structured data fields
- Best practices and guidelines
- Management-focused metrics and tracking

Each template is designed to help manage software effectively across its entire lifecycle - from planning and development to operations and maintenance.
